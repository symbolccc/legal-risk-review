# 返点与结算单审理细则

> 按需加载。SKILL.md 主干只保留「审什么」，本文件是分类流程与核对项全集。

## 五类流程

| 类型 | 对象 | 审理要点 |
| :-- | :-- | :-- |
| A 类 | 客户结算单 | 金额、税额、税率、发票类型与合同一致 |
| B 类 | 媒体结算单 | 媒体账期与垫款口径一致 |
| C 类 | 非框合同 | 无框架依据，须逐项核对合同要件 |
| D 类 | 变更审批表 | 变更前后差异必须逐项点名，含描述同步 |
| E 类 | 离职转签单 | 主体与签署链完整性 |

五类之后统一执行通用归档动作。

## 全维度核对项（缺一不可）

审核类型 / 回款时间 / 合同履行期限 / 金额 / 税额 / 税率 / 发票类型 / 收款主体 / 开票主体

其中**收款主体与开票主体必须一致**；不一致直接退回，不做解释性放行。

## 异常处理

- **强制升级清单**：命中即上报，不得自行判断放行。
- **红线退回规则**：直接退回并逐项点名缺什么，禁止笼统写「材料不全」。
- **标准审批话术**：审批回复使用 `../assets/approval-replies.md` 的对照表，不自创措辞。

## 常见退回情形速查

| 情形 | 处理 |
| :-- | :-- |
| 申请类型与实际业务不符 | 退回，问清本次到底做了什么业务 |
| 金额、账期与描述不一致 | 退回，要求同步修改描述与选项 |
| 描述被改动后选项未同步 | 退回，指出具体哪几处需清除或改选 |
| 缺证照或后台截图 | 退回，逐项点名缺件 |
| GMV 年度或时效不符 | 退回，不得用更早年度替代 |
| 附件模糊、空附件、错误附件 | 需人工核验，不得猜测内容 |
