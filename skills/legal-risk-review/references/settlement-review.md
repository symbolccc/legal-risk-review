# 返点与结算单审理细则

> 按需加载。SKILL.md 主干只保留「审什么」，本文件是分类流程与核对项全集。

## 五类流程

| 类型 | 对象 | 审理要点 |
| :-- | :-- | :-- |
| A 类 | 客户结算单 | 金额、税额、税率、发票类型与合同一致 |
| B 类 | 媒体结算单 | 媒体账期与垫款口径一致 |
| C 类 | 非框合同 | 无框架依据，须逐项核对合同要件 |
| D 类 | 变更审批表 | 变更前后差异必须逐项点名，含描述同步 |
| E 类 | 离职转签单 | 主体与签署链完整性 |

五类之后统一执行通用归档动作。

## 全维度核对项（缺一不可）

审核类型 / 回款时间 / 合同履行期限 / 金额 / 税额 / 税率 / 发票类型 / 收款主体 / 开票主体

其中**收款主体与开票主体必须一致**；不一致直接退回，不做解释性放行。

## 算术与资格校验（逆向检查补入）

### 1. 税额必须由金额与税率算出来，不能只比对

| 校验 | 规则 | 不通过 |
| :-- | :-- | :-- |
| 税额自洽 | 不含税金额 × 税率 = 税额 | fail，要求重算 |
| 价税分离 | 不含税金额 ＋ 税额 = 价税合计 | fail |
| 税率与业务匹配 | 广告/服务类通常为 6%，货物类 13%；与合同附件约定比对 | 不一致即 fail，不按「行业惯例」放行 |

只核对「结算单税额 = 合同税额」是不够的——两边可能同时错。必须独立重算一遍。

### 2. 金额差异零容差，但允许说明

| 情况 | 处理 |
| :-- | :-- |
| 结算金额与排期表/确认单合计完全一致 | pass |
| 差异 ≤ 0.01 元（四舍五入） | pass，但需注明为舍入差异 |
| 差异 > 0.01 元 | fail，要求书面说明差异来源，不得自行取其一 |
| 结算金额大于合同/框架剩余额度 | fail 并升级 |

### 3. 发票类型与纳税人资格联动

| 开票方资格 | 可开具 | 判定 |
| :-- | :-- | :-- |
| 一般纳税人 | 增值税专用发票、普票 | 与结算单一致即 pass |
| 小规模纳税人 | 普票；专票需符合当期政策 | 出现专票时转人工核验，不得直接 pass |
| 资格无法从证据确认 | — | uncertain |

### 4. 返点方向必须写明

返点是**媒体→我方**还是**我方→客户**，决定收付款主体、发票流向与会计处理。

- 结算单未标注方向，或方向与合同条款矛盾 → fail，退回澄清。
- 不得根据金额大小或习惯推断方向。

### 5. 跨期结算检查

| 检查 | 规则 |
| :-- | :-- |
| 业务发生期间 ⊆ 合同期限 | 否则 fail（用旧合同结算新业务是常见风险） |
| 结算单日期晚于业务结束日 | 正常 |
| 结算单日期早于业务结束日 | fail，属预估结算，需人工确认 |
| 合同已到期后仍发生结算 | fail 并升级 |

### 6. A 类与 B 类的镜像交叉核对

同一笔业务同时存在客户结算单（A）与媒体结算单（B）时：

- A 类收入金额应 ≥ B 类成本金额，否则毛利为负 → 需人工核验并说明；
- 两者的业务期间、平台、项目名应能对应，对不上即为串单风险 → fail；
- 只审到其中一类时，在 `model_notes` 注明「未做镜像核对，缺另一类单据」。

### 7. D 类变更的基准

变更审批表必须指明比对基准：**以原审批件为基准**逐项列出差异，禁止只描述变更后的新状态。
变更前值、变更后值、变更原因三列缺一不可。

### 8. E 类转签的主体存续

转签后的承接主体须经营状态核验（存续/在业）。已注销、吊销主体签署的转签协议无效 → fail。

### 9. 红字与冲销

出现负数金额或红字发票时，必须附原蓝字发票号与冲销原因；缺任一项 → fail。

## 异常处理

- **强制升级清单**：命中即上报，不得自行判断放行。
- **红线退回规则**：直接退回并逐项点名缺什么，禁止笼统写「材料不全」。
- **标准审批话术**：审批回复使用 `../assets/approval-replies.md` 的对照表，不自创措辞。
- **退回轮次**：同一单据第三次退回时转上级，不再由本人继续往返。

## 常见退回情形速查

| 情形 | 处理 |
| :-- | :-- |
| 申请类型与实际业务不符 | 退回，问清本次到底做了什么业务 |
| 金额、账期与描述不一致 | 退回，要求同步修改描述与选项 |
| 描述被改动后选项未同步 | 退回，指出具体哪几处需清除或改选 |
| 缺证照或后台截图 | 退回，逐项点名缺件 |
| GMV 年度或时效不符 | 退回，不得用更早年度替代 |
| 附件模糊、空附件、错误附件 | 需人工核验，不得猜测内容 |
| 税额与金额×税率不符 | 退回重算，不得只对齐合同值 |
| 结算金额大于框架剩余额度 | 退回并升级 |
| 返点方向未标注 | 退回澄清，不得推断 |
| 业务期间超出合同期限 | 退回 |
| 负数/红字无对应蓝字发票号 | 退回 |
