# 证据来源契约

> 定义「什么算证据、冲突时信谁、取不到时怎么办」。这是本技能最容易被忽略但最关键的一层。

## 来源优先级

| 优先级 | 来源 | 用途 | 说明 |
| :-- | :-- | :-- | :-- |
| 1 | 附件原件（营业执照、银行开户证明、纳税人证明） | 证照类字段的最终依据 | 图片/PDF 原件，非转述 |
| 2 | OA 自动带出的工商/第三方信息 | 企业信息比对基准 | 即 R4 所指基准 |
| 3 | OA 表单字段（业务方填写） | 被审对象，不是证据 | 与 1/2 冲突时以 1/2 为准 |
| 4 | 业务方在聊天中的补充说明 | 仅用于澄清事实 | 不得替代证照原件 |

**核心原则**：表单是被审的东西，不是证据。表单与证据不一致，判表单错。

## 逐字符规则

以下字段必须**逐字符**确认，任一位无法确认即不得判通过：

- 统一社会信用代码
- 银行账号
- 注册资本金额

图片模糊、反光、水印遮挡、截断导致无法逐字符读取时 → `需人工核验`，不得按「看起来一样」放行。

## 容错范围（仅此三处允许差异）

| 字段 | 允许的省略 | 不允许的差异 |
| :-- | :-- | :-- |
| 注册地址 | 省/市/区层级省略（R6） | 街道门牌不一致 |
| 主体名称 | 无（括号、简称、英文名是否等价属未确认项） | 任何实质差异 |
| 开户行名称 | 无（简称是否允许属未确认项） | 任何实质差异 |

未确认项一律走 `需人工核验`，不得自行放宽。

## 来源缺失的处理

必须显式区分三种情况，不得合并表述：

| 情况 | 措辞 | 结论 |
| :-- | :-- | :-- |
| 该来源未提供 / 未上传 | 「未提供 X 附件」 | 退回并要求补件 |
| 该来源已读取但字段无法辨认 | 「X 已读取，字段不可辨认」 | 需人工核验 |
| 该来源不在本系统内 | 「未查询 X（数据在 Y 系统）」 | ⚠️ 待补，不得推断不存在 |

**「未查到 ≠ 不存在」**：第三种情况严禁写成「无此记录」。

## 输出必须声明的内容

每次审核结论都要写清：

1. 实际读取了哪些来源（列名）
2. 哪些来源未能读取，原因是什么
3. 每个判定字段对应的是哪个来源
4. 无法确认的字段是否已全部标为「需人工核验」

## 禁止

- 用行业常识、历史单据、外部公开信息补全当前单据缺少的字段。
- 把业务方填报的金额、账期当作已验证事实。
- 在来源不足时给出「建议通过」。
- 把他人成果或业务方数据记入审核人的个人产出。
