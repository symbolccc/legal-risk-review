# 垫款 / 风控意见输出模板

> 直接复制填写。方括号内为必填占位；无数据的段落写「无」或「未提供」，不得整段删除——
> 删除会让复核人无法区分「没有」和「忘了写」。

```markdown
# [客户全称]-[业务名称]项目

**客户信息**：[行业] [直客/代理]，[成立年份] 年成立，[注册资本/实缴]，
[上市或国资背景等有则写]，主营 [产品/服务]，[关联主体数量与名称]，
整体处于 [经营状态]。

**合作情况**：合作 [业务类型]，[合同状态：已签/签订中/续签]，
合同周期为 [起] 至 [止]；[是否单次投放]；投放平台为 [平台]；
付款模式为 [先票后款/预付款]，[电汇/承兑]；[合同模板归属与定稿状态]。

**账期说明**：

| 业务线 | 金额 | 客户付款节点 | 穿透后实际账期 | 媒体账期 | 是否实际垫款 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| [品牌] | [ ] | [上线后 N 日内付款] | [N 天] | [N 天 / 无账期] | [是/否] |
| [效果] | [ ] | [对账单确认后 N 个工作日内] | [N 天] | [ ] | [ ] |
| [社交] | [ ] | [下单后 N 日内付款] | [N 天] | [ ] | [ ] |

穿透计算过程（必填，不可只给结果）：

- [业务线]：合同执行期 [a] ＋ 验收期 [b] ＋ 对账开票期 [c] ＋ 信用账期 [d] ＝ [合计] 天

**GMV**：[年度] [平台] [销量/销售额趋势]。缺少年份或平台时写「缺少 [X] 数据」。

**综上**：[业务线 A] [N] 天账期、[有无]垫款敞口；[业务线 B] [N] 天、
[是否]需实际垫款。[结论：无异议 / 建议压缩额度 / 需人工核验]。

**未确认事项**：[列出仍需业务方或上级确认的点；无则写「无」]
```

## 填写纪律

1. 「综上」必须同时给出**账期天数**、**是否实际垫款**、**有无异议**三件事，缺一不可。
2. 穿透计算过程要写出来。只写「账期 180 天」而不给构成，视为未完成审核。
3. 「次月末支付上月消耗」按**次次月末**计，别照抄 180 天。
4. 风险提示、主体与币种两段**默认不写**，除非用户明确要求。
5. 金额、比例等业务方填报值只作被审对象，不写成审核人的判断依据。
6. 证据不足时，「综上」写「需人工核验」，不得写「无异议」。
