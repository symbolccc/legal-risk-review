# 标准审批话术对照表

> 审批回复不自创措辞。统一口径的目的是让退回理由可追溯、可统计。

| 场景 | 标准回复 | 禁止写法 |
| :-- | :-- | :-- |
| 缺证照附件 | 「缺 [营业执照/开户证明/一般纳税人证明/后台截图]，请补齐后重新提交。」 | 「材料不全」 |
| 缺多项 | 逐项列出全部缺件，一次性退回 | 分次挤牙膏式退回 |
| 申请类型与业务不符 | 「本次未涉及 [品牌] 投放，为何申请 [品牌] 风控？请确认业务类型后重填。」 | 「类型错了，改一下」 |
| 描述与选项不一致 | 「请把变更内容描述一并修改；[金额]、[账期] 需清除，[选项] 改选 [正确值]。」 | 「自己看一下哪里不对」 |
| 账期算错 | 「[X] 天与穿透计算不符：合同执行期 [a]＋验收期 [b]＋对账开票期 [c]＋信用账期 [d]＝[合计] 天，请修正。」 | 「账期不对」 |
| 主体与开票方不一致 | 「收款主体与开票主体不一致，请核实后重提。」 | 解释性放行 |
| GMV 时效不符 | 「[年度] GMV 不满足时效要求：当年申请只看上年全年。」 | 「数据太旧」 |
| 附件模糊 | 「附件已上传但 [字段] 无法逐字符辨认，需人工核验原件。」 | 「看不清，按表单填的算」 |
| 规则未配置 | 「[判断项] 的口径尚未确认，按规则输出需人工核验。」 | 按行业惯例自行判断 |
| 通过 | 「经核验，申请信息与附件一致。」 | 「没问题」 |

## 退回三原则

1. **点名到字段**：说清哪一个、错在哪、应改成什么。
2. **一次说完**：同一单据的所有问题一次性列出，不分多轮。
3. **不留模糊空间**：不用「请核实」「请注意」这类不指明动作的措辞。
